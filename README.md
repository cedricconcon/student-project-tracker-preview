# Student Project Tracker

A simple project tracker app for managing student projects — add, edit, 
delete, and track status (Not Started, In Progress, Completed) with due dates.

🔗 **Live Preview (Static Version):** [link dito pag nakuha na]

## About this repo
This repo contains the **static frontend preview** (HTML/CSS/JS) of the project, 
built for showcasing the UI and design.

The full working version is built with **Java (JSP/Servlets) + Maven + Apache Tomcat**, 
which includes real backend functionality — adding, editing, and saving project 
data to the server. That version requires a Java environment to run and is not 
hosted live here.

## Tech Stack
- Frontend: HTML, CSS (Tailwind), JavaScript
- Backend (full version): Java, JSP, Servlets, Apache Tomcat, Maven
